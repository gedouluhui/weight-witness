The unit suite includes invalid headers, duplicate keys, metadata, shape/offset failures, empty/scalar tensors, shard ownership, source modification, tolerances, signed zero, nonfinite values, BF16 bit decoding, chunk-size invariance, JSON/HTML escaping, output protection and CLI argument errors. Optional oracle absence is reported as a skip, not a pass.

The mutation suite removes index ownership checks, duplicate-key checks, numeric threshold checks, BF16 bit-shift correctness, HTML escaping and both CLI source-output guards. A nonzero process exit alone is insufficient: each variant must fail its named assertion. Mutations run only in disposable copied trees.

## Independent review and fixes

The first read-only review found that Python JSON accepted isolated Unicode surrogates and that a zero dimension could hide an earlier unsigned-64-bit product overflow. Both were independently reproduced, given failing regressions, and fixed at the parser boundary. Native safetensors rejects the same counterexamples.

A second whole-core review identified two error-state inconsistencies: invalid argparse values did not emit JSON, and rendering an error object hid its reason behind an unknown/zero-count report. Both were reproduced and fixed. A separate scoped review confirmed both fixes and checked help/version and injection regressions. No open blocker was reported in that scoped review. This is not an exhaustive formal audit.

## Synthetic demonstration

The demo has 12 tensors in the base checkpoint. Its candidate comparison contains a 13-name union: 6 equal, 4 changed, 1 added, 1 removed, 1 dtype-incompatible. These counts come from `compare_checkpoints` on files generated by `examples/make_demo.py`, not a hand-authored UI fixture. The same tensors re-sharded into two files compare equal. A deliberately wrong index points a real key to the wrong existing shard and is rejected.

To rebuild the public report after generating `artifacts/demo`:

```sh
python examples/render_demo.py
```

The page is explicitly marked synthetic. It is not evidence of a trained model, real production incident, speedup, or accuracy improvement.

## Not verified here

- GPU behavior, model quality, multi-billion-parameter throughput/RSS, or real users.
- Safari/Firefox, screen readers, or physical mobile devices.
- Windows symlink behavior on the maintainer's machine. The Linux hosted CI run described below did execute and pass the symlink rejection test.
- Packed/sub-byte dtypes, unknown future dtypes, nested shard paths, and hostile concurrent writers: outside the declared v0.1 scope.
- A universal absence of sensitive information. A scoped pre-publication text/path scan found no credential/private-path pattern matches in selected source files; arbitrary tensor names still need human review before sharing a report.
